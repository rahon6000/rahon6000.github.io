# 기획

기본 아이디어 : 덱빌딩 장르 + 2D 격겜 장르 짬뽕하면 나름 맛있지 않을까?

## 재밌는 포인트가 뭔데?

### 덱 빌딩

덱빌딩 장르의 포인트는 선택과 그로인해 만들어지는 시너지, 뽕맛임. 나 같은 경우는 좋고 나쁨을 떠나  원하는 컨셉의 덱을 맞추는 플레이를 좋아했음.

> 예시 : 슬더스 도적 콤보덱 맞추기. 발라트로 원수트 덱 맞추기.

이런 재미를 주려면 여러 가능성에서 생길 수 있는 **시너지**를 마련하고 컨셉플을 위한 특성들이 필요함. 

특성 예시
- 슬더스 : 민첩, 힘 같은 스탯들. 드로우, 소멸 같은 카드 키워드들.
- 발라트로 : 칩, mult, mult 곱셈.

### 격겜

격겜의 재미는 콤보 깎는 재미, 사기치는 재미, 심리전 세가지 정도인듯.

**콤보 깎는 재미**는 정형적인 콤보 연습하는 재미도 있지만 공콤 애드립을 넣는 재미가 중요하다고 생각함. (와 이걸 건져서 콤보를 넣네 같은 생각이 들어야 함.) 

**사기치는 재미** 는 파훼하기 힘든 기술이나 패턴으로 날먹하는 재미인데, 당하는 입장에선 열받는다는게 양날의 검으로 작용함. 사기를 당하고도 '그래 이건 인정이지' 라는 반응이 나올 수 있으면 그나마 베스트임. 예를 들면 미친놈처럼 승룡을 자주쓰는 케이스는 그래도 리스크를 갖고 행동하는거라 인정의 여지가 있음.

**심리전** 은 불균등한 리스크를 가진 가위바위보가 성립할 때, 혹은 습관을 캐치해 예상대로 플레이 했을 때 재미임. 문제는 가위, 바위, 보를 내는 것 조차 힘들면 이 재미를 맛보기 힘들다는 점임.

## 그래서 두 장르를 어떻게 믹스할 수 있어?

1. 일단 크게는 1대1 대전게임이기 때문에 하스스톤마냥 서로 덱을 갖고 싸우는 형식이어야 함.

2. 일단 격겜으로서나 카드겜으로서나 호흡이 되게 빨라야 할 것 같음.

내가 뽑은 카드로 사기치고 심리전을 해보고 빨리 빨리 다음 턴이나 라운드로 넘어갈 수 있으면 좋을 것 같음.

3. 카드는 슬더스 유물같은 느낌으로 패시브 사용하지 않을까 싶음.

예를 들면 p 계열이 빨라지거나. 체력이 감소하거나. 무적프레임을 상향받거나 한다는 식으로 modifier 개념이 들어갈 수 있을 것 같음.

4. 소모성 카드도 있을 순 있다고 본다.

레브투의 죠니의 동전처럼 소모성 카드들이 있어도 괜찮을 법 하다. (대신 얻을 때 여러장 얻을 수 있거나 슬더스처럼 추방존에서 퍼올릴 수 있거나...)

5. 덱에서 드로우하는 개념도 가능할까?

1라운드 끝나면 멀리건 같은걸 하거나. 전투력엔 영향 없지만 핸드를 늘릴 수 있는 카드를 뽑거나.

6. 내 패와 상대 패는 공개인가? 비공개인가? 아니면 일부만 공개하나?

전투에 확실히 영향을 주는 경우는 공개해야 할 것 같음. (1프 빨라지는 거 눈치챌 수 없자나)

근데 숨기고싶은 패가 있어도 재밌을 것 같음. (저번 라운드 막힌 리버설 횟수만큼 공격력 + 같은 느낌의 카드)

7. 캐릭터나 아키타입은 어떻게?

아키타입이 너무 많아지는 건 너무 힘들 것 같음. (덱에 의한 개성 + 캐릭터 개성 = 너무 생각할 것이 많음)

그냥 일반적으로 생각할 수 있는 아키타입 2-3개 정도에 덱에 의한 개성을 섞는 쪽이 좋지 않을까 싶다.

- 류/캔/카이/솔 일반적인 스탠다드형
- 가일/테스타/베놈 공간 장악형
- 이노/밀리아 이지선다형

8. 카드나 키워드는 어떻게?

눈에 보이는 효과의 카드들과 보이지 않는 카드들로 나눠야 할 듯.

- 눈에 보이는 효과 : 프레임, 공격력, 판정, 체력, 게이지 회복력 등의 상향/하향
- 눈에 보이지 않는 효과 : 다음 라운드에 적용되는 카드, 다음 라운드부터 적용되는 카드, 매치포인트에만 적용되는 카드, 특정 상황에서 공개하고 스택을 쌓는 카드 등.

키워드는?

- 체력
- 근성
- 공격력
- 판정단계
- 게이지 회복력
- 카운터 횟수
- 리버설 횟수 (아님 반대로 가드된 리버설 횟수)

유물이나 조커처럼 버려지지 않고 (플레이 되지 않고) 상시적용될만한 것들은?

- 앞선 키워드 활용한 뭔가 (예시 : 카운터 당할 때 마다 강해진다)
- 아예 각필을 추가해준다
- 버스트마냥 임의로 사용할 수 있는 방어옵션 (혹은 원래 있는 방어옵션 강화)

## 대략적인 플레이 흐름은 어떨까나?

보통 격겜이 그렇지만 싱글과 대전이 좀 느낌이 달라짐.

### 게임 모드

- 싱글 : 슬더스처럼 두꺼운 덱 가지고 진행. 싱글 전용 사기치기 가능한 카드 있어도 될 듯.
- 대전 : 제한된 덱을 들고 진행.

### 턴과 라운드

카드게임이 턴 베이스로 진행되는 것 처럼, 격겜은 라운드 베이스로 진행될 것 같다.

> 이 라운드는 킹오파처럼 체력 일부회복만 할지, 아예 새 라운드가 될지, 게이지들은 어떻게 할지 세부사항은 조정 필요.

### 드로우

라운드 시작 전 덱에서 카드를 N 장 드로우 한다. 여기서 원하는 만큼 M 장 플레이 하고, 플레이한 M 장의 카드들은 이번 라운드에 적용된다. (패시브일수도 있고, 나중에 적용되는 패시브/퀘스트일수도 있고, 필드에 계속 남아있는 적립형, 기술형 카드들일수도 있고.)

사용하지 않은 카드들은 핸드에 남기거나 L 장 만큼 디스카드 하면 될 듯. (패순환이나 서치를 위해서 많이 버리고 싶을수도 있어서)

패를 모두 버리면 덱으로 다시 셔플하거나 (슬더스) 더 못뽑거나 (하스스톤 발라트로) 둘 중 어떤걸로 할지는 선택

### 공방

평범한 격겜처럼 진행하는데, 템포가 중요할 것 같음. 가뜩이나 플레이하는 시간도 있는데, 한 라운드가 너무 길면 안될 것 같음. 심리전이 2~3번 정도는 있을 수 있어야 할 것 같고 심리전을 위한 가위바위보는 내기 쉬워야 할 것 같음.

리버설은 무적시간 널널하게 줘서 안전점프로 파훼하기 쉽게 만들자.
깔아두기 좋은 기술은 리버설을 못이기도록 후경직 충분히 길게.
안전점프들은 리버설은 이기지만 후상황은 위의 기술보단 안좋게.
잡기는 빠르지만 리턴 적게.

### 승패

그냥 격겜처럼 라운드 따면 승리.

근데 격겜에서 기술이나 패턴으로 사기치는 것 처럼, 덱으로도 (확률은 별로지만) 사기쳐서 이길 수 있게 하면 재밌을 것 같다.

지고나서도 참고가 될 수 있게 리포트가 나오면 좋겠음 길티마냥 쓸데없는 수치 보여주지 말고, 리버설 성공률이나 카운터 성공률, 최대 데미지 시동기술, 잡기 회피, 리버설 회피, 카드시너지, 게이지 사용 횟수등등 오버워치 메달처럼 여길 수 있는 건 많음.

### 카드 언락은?

싱글, 대전에서 포인트 모아서 부스터 뜯어서 모으셈
아니면 발라트로처럼 해금조건 만족해서 보상으로 얻거나

## 개발을 얼마나 해야 함?

크게 그래픽, 프로그래밍, 음악, UX 디자인 정도로 나눌 수 있겠지

그래픽 음악은 처음부터 너무 신경쓰지 말자. 디렉션이 없는 상황에서 뭘 해봤자 안되는 부분임

### 코딩

최대한 추상화 예쁘게 해서 확장 가능하게 해야 함. 카드게임은 키워드 추가되거나 확장되는 일이 많아서 거의 모든 상황이 추가적으로 커스터마이즈 가능해야 재밌을 것 같음.

1. 드로우, 플레이, 디스카드, 컴뱃 페이즈는 거의 고정 가능할 듯 (승리 라운드 수는 유동적일 수도 있을 듯.)
2. 공판정 피판정은 동적으로 결정 가능해야 함. 이거 하드코딩하고 앉아있으면 답이 없다. 판정 확대 축소도 가능할 것 같은 상황이라...
3. 국룰인 60 프레임단위의 시간 흐름
4. 세이브, 로드, 씬 이동, 메뉴 등 국룰적인 부분들
5. 다른 사람들이 만든 소스코드도 많이 참고하자.
